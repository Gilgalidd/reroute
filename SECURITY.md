# Security policy

Signpost sits between every link you click and the browser that opens it, so
it is held to a high standard. The threat model and the controls in place are
described in [docs/security.md](docs/security.md).

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Use GitHub's
private vulnerability reporting on this repository ("Security" tab →
"Report a vulnerability"). You will receive an acknowledgement within a few
days and a fix or mitigation plan as soon as possible.

## Supported versions

Only the latest release receives security fixes.
